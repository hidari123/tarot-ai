feat: dialogue quality overhaul — citation integrity + retrieval precision + anti-drift

Data-driven fixes from real session analysis (SQLite llm_usage/tool_calls):

1. Citation index bug (correctness): session.ragHits was overwritten on each
   rag_search; with multi-query sessions the [n] numbers in readings pointed
   at wrong knowledge panel rows. Now hits accumulate by chunkId (dedup,
   cap 12) so [n] always matches the panel.

2. Card-name exact channel (retrieval precision): BM25 2-gram matching made
   宝剑十 pull in 权杖十/星币十 (shared low-IDF grams). Added third
   retrieval channel: closed-vocabulary card name extraction forces
   explicitly mentioned cards to top via RRF. Synced to
   mcp-server/rag-engine.cjs. New scripts/test-rag-quality.cjs verifies.

3. Supervisor anti-drift (stability): model occasionally skipped all tools
   and answered directly (money case: 10 tools -> 0). Two defenses: prompt
   hard rule (tools-only, followup exempt) + code-level guard injecting a
   corrective message, retries up to 2x before accepting bare text.
   Kept supervisor thinking enabled — disabling it made drift worse.

4. Followup anti-hallucination: followup prompt embeds full card knowledge
   + RAG digest so history compression cannot starve the model of
   canonical card meanings.

5. Analyst live streaming: analyst notes stream as reasoning events,
   filling the silent gap between card selection and writer first token.

6. Followup bubble UI: CitedReading splits paragraphs; 【追问】 lines
   render as right-aligned indigo user bubbles.

Also: analyst streaming max_tokens 2500; debug scripts (debug-sse.mjs,
check-recent-sessions.cjs, test-rag-quality.cjs).

Eval: 97% two consecutive runs (77% before rag_hits fix; 50-63% during
CoT experiment; unstable before anti-drift guard).
