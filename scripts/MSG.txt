feat: share card copy via LLM summarization — no truncation

User asked: don't truncate the reading on the share card; summarize it to
a fitting length instead of cutting it off.

- New POST /api/summarize: sends the full per-card reading to the LLM with
  a copywriting prompt (80-150 chars, keep the strongest conclusion + one
  actionable step, strip section headers and [n] citation marks, keep the
  reader's tone, output text only). Falls back to the DB-stored reading
  when body.reading is missing; strips think tags / code fences.
- ShareCardButton: "正在提炼文案…" state while summarizing, then renders
  the canvas with the distilled copy. Falls back to the locally extracted
  closing passage if the API fails.
- Canvas: adaptive font (26/28/32px by length) and up to 8 lines; removed
  the ellipsis / "see full reading" hint — the summary IS the full message
  now, nothing is cut.
- ShareCardData: fullReading passes the complete text; summary becomes
  the fallback only.

Verified live: 788-char per-card reading → 121-char coherent share copy
(conclusion + action advice, no section headers, no citation numbers).
